LOCAL FILE CONVERTER

파일은 내 PC에서.
형식만 가볍게 바꿉니다.

미디어, Office 문서, PDF를 필요한 형식으로 변환하는 Windows용 로컬 도구입니다. 입력 파일은 외부 서버로 전송되지 않습니다.

설치 및 실행 보기

THREE STEPS

처음 한 번만 준비하세요.

01

Python 설치

Python 3.10 이상을 설치합니다. 설치 화면에서 Add Python to PATH를 선택하세요.

02

변환 엔진 설치

필요한 변환 종류에 맞게 FFmpeg, LibreOffice, Ghostscript 또는 Poppler를 설치합니다.

03

도구 실행

로컬_변환기_실행.bat를 더블클릭합니다. 또는 이 폴더에서 Python 명령으로 GUI를 엽니다.

이 도구는 별도 Python 패키지 설치가 필요하지 않습니다. 변환에 필요한 외부 프로그램만 준비하면 됩니다.

DESKTOP APP

화면에서 바로 변환.

파일 선택, 변환 형식, 출력 폴더를 정한 뒤 변환 시작을 누르세요. 목록에 없는 형식도 직접 입력할 수 있으며, 실제 지원 여부는 FFmpeg가 결정합니다.

로컬_변환기_실행.bat 또는 python converter_gui.py

기본 흐름

  1. 변환할 파일을 선택합니다.
  2. mp3, mp4, pdf, jpg 등 목표 확장자를 선택하거나 직접 입력합니다.
  3. 필요하면 출력 폴더와 덮어쓰기·압축 옵션을 정합니다.
  4. 변환 시작을 눌러 결과 경로를 확인합니다.

알아둘 점

  • 같은 이름의 결과가 있으면 기본으로 중단됩니다.
  • 덮어쓰기를 선택하면 기존 결과 파일을 교체합니다.
  • 진행 중에도 창은 응답하며, 완료 후 결과 경로가 표시됩니다.

WHAT YOU CAN CONVERT

형식에 맞는 엔진을 사용합니다.

대상가능한 작업필요한 프로그램
오디오·영상FFmpeg가 읽고 쓸 수 있는 형식 사이의 변환. 예: MP4 → MP3, WAV → M4A.FFmpeg
Office 문서DOC/DOCX, PPT/PPTX, XLS/XLSX, ODT/ODP/ODS, RTF/CSV → PDF.LibreOffice
PDF 용량 줄이기screen(작은 용량), ebook(균형), printer(고품질) 중 하나를 선택.Ghostscript
PDF → 이미지모든 페이지를 JPG 또는 PNG로 저장. 기본 해상도는 150 DPI.Poppler

Office 원본 내부 이미지를 다시 압축하는 기능은 레이아웃 손상 위험 때문에 제공하지 않습니다. Office 문서를 PDF로 바꾼 뒤 PDF 압축을 적용할 수 있습니다.

COMMAND LINE

터미널에서도 정확하게.

미디어 변환

python local_converter.py video.mp4 --to mp3 python local_converter.py recording.wav --to m4a --output-dir converted

Office 문서 → PDF

python local_converter.py slides.pptx --to pdf --output-dir converted python local_converter.py report.docx --to pdf --overwrite

PDF 압축과 이미지 저장

python local_converter.py report.pdf --to pdf --compress --quality ebook --overwrite python local_converter.py manual.pdf --to jpg --output-dir images --dpi 200

--overwrite는 기존 결과를 교체하고, --output-dir은 결과 폴더를 지정합니다. PDF → 이미지 변환에서 --dpi는 30 이상이어야 합니다.

TROUBLESHOOTING

막히는 지점을 빠르게 찾기.

“FFmpeg was not found”가 표시됩니다.

FFmpeg를 설치한 뒤 PATH에 추가하고 새 PowerShell 또는 명령 프롬프트를 여세요. 명령 창에서 ffmpeg -version이 실행되는지 확인합니다.

Office PDF 변환이 시작되지 않습니다.

LibreOffice를 설치하세요. 프로그램은 PATH와 기본 Windows 설치 경로를 자동으로 확인합니다. 이미 설치했다면 프로그램을 완전히 종료한 뒤 다시 시도하세요.

PDF 압축 또는 PDF → 이미지가 실패합니다.

압축에는 Ghostscript, 이미지 저장에는 Poppler가 각각 필요합니다. 설치 후 실행 파일 폴더를 PATH에 추가하고 새 터미널에서 다시 실행하세요.

결과 파일이 이미 있다고 나옵니다.

다른 출력 폴더를 선택하거나 GUI의 덮어쓰기 옵션, 명령줄의 --overwrite를 사용하세요.
