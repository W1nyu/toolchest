LOCAL IMAGE TO TEXT

사진 속 글자를,
내 PC에서 바로 텍스트로.

화면 캡처나 사진 속 문서를 Windows 내장 인식기로 읽어 편집 가능한 텍스트, 또는 원본을 그대로 보여주는 검색 가능한 PDF로 저장하는 로컬 도구입니다. 이미지는 외부로 전송되지 않습니다.

설치 및 실행 보기

THREE STEPS

따로 설치할 것이 거의 없습니다.

01

Python 설치

Python 3.10 이상을 설치합니다. 설치 화면에서 Add Python to PATH를 선택하세요.

02

한국어 인식기 확인

대부분의 Windows 11에는 기본으로 들어 있습니다. 없다면 설정 → 시간 및 언어 → 언어 및 지역 → 한국어의 언어 옵션에서 광학 문자 인식을 설치하세요.

03

앱 실행

scripts 폴더의 로컬_변환기_실행.bat를 더블클릭한 뒤 이미지 텍스트 탭을 엽니다. 별도 실행 파일은 없습니다.

이 기능은 Windows 내장 OCR(Windows.Media.Ocr)만 사용합니다. 별도 Python 패키지 설치, 계정 등록, API 키가 필요 없습니다.

DESKTOP APP

넣고, 추출하고, 고치고, 저장까지 한 화면에서.

파일 변환기와 같은 앱의 이미지 텍스트 탭입니다. 이미지를 불러오면 미리보기와 함께 파일명 · 너비×높이가 표시되고, 텍스트 추출 뒤에는 결과를 직접 고칠 수 있는 편집창이 열립니다.

scripts\로컬_변환기_실행.bat 또는 python src\converter_gui.py

기본 흐름

  1. 이미지 텍스트 탭을 엽니다.
  2. 이미지 불러오기를 누르거나, 편집창 밖에 커서를 둔 채 Ctrl+V로 복사한 이미지를 붙여넣습니다.
  3. 텍스트 추출 또는 PDF로 바로 저장을 눌러 인식을 시작합니다.
  4. 편집창에서 오타를 고칩니다.
  5. 전체 복사, .txt 저장, .md 저장, PDF 저장 중 필요한 방식을 선택합니다.

알아둘 점

  • Ctrl+V는 편집창 밖에 초점이 있을 때만 이미지를 붙여넣습니다. 편집창 안에서는 평범한 텍스트 붙여넣기로 동작합니다.
  • 표처럼 배치된 내용은 같은 줄로 인식된 항목이 탭으로 구분되어 나오므로, 엑셀이나 노션에 그대로 붙여넣으면 열이 나뉩니다.
  • 인식이 틀리게 읽은 글자를 다른 글자로 추측해 고쳐주지는 않습니다. 잘못 읽은 글자는 편집창에서 직접 고쳐야 합니다.
  • PDF 저장은 텍스트 추출 시점의 인식 결과를 그대로 사용합니다. 편집창에서 고친 내용은 PDF에 반영되지 않습니다 — 고친 내용을 남기려면 .txt 또는 .md로 저장하세요.

표가 많은 이미지라면 PDF로 바로 저장을 권합니다. 텍스트로 펼치면 행과 열을 맞춰야 하지만, PDF는 원본 레이아웃 위에 글자를 제자리에 얹으므로 열이 어긋날 일이 없습니다. 필요한 부분만 드래그해 복사하세요.

흰 캔버스 체크박스는 투명한 부분을 흰색으로 채운 뒤 인식합니다. 클립보드로 복사한 이미지는 투명 영역이 검게 굳어 그 위 글자를 읽지 못하는 경우가 있는데, 이 옵션이 그림판에 붙여넣었다 다시 복사하는 것과 같은 역할을 합니다. 기본값은 켜짐이며, 실측에서 끈 경우 380자에 그친 이미지가 켠 경우 2365자까지 읽혔습니다. 드물게 결과가 더 나쁘면 꺼서 비교해 보세요.

COMMAND LINE

반복 작업이나 스크립트에는 명령줄로.

기본 실행 (표준 출력)

python src\image_to_text.py assets\samples\ex.png

텍스트 파일로 저장

python src\image_to_text.py assets\samples\ex.png --output result.txt

검색 가능한 PDF로 저장

python src\image_to_text.py assets\samples\ex.png --pdf result.pdf

클립보드 이미지, 확대 배율 올리기

python src\image_to_text.py --scale 4

이미지 경로를 생략하면 클립보드에 있는 이미지를 사용합니다. --scale의 기본값은 3으로, 인식 전에 이미지를 그만큼 확대해 정확도를 높입니다. 실측에서 2배보다 3배가 뚜렷이 나았고 그 이상은 거의 차이가 없었습니다. 긴 이미지는 인식기 한계(긴 변 10000px)에 맞춰 배율이 자동으로 낮아집니다. 작은 글자가 잘 안 읽히면 배율을 올려보세요.

PRIVACY & LIMITS

내 PC 안에서 끝나고,
못 고치는 것은 못 고칩니다.

로컬 처리

Windows 내장 OCR(Windows.Media.Ocr)만 사용합니다. 설치, 로그인, API 키가 필요 없고 이미지는 인터넷으로 전송되지 않습니다.

인식 언어와 확대

한국어와 영어를 함께 인식합니다. 인식 전 이미지를 2배로 확대하는데, 이 확대가 인식 정확도를 눈에 띄게 높이기 때문입니다. 한국어 인식기가 없는 PC에서는 사용할 수 없습니다.

남기는 문자

숫자, 한글, 영문, 공백, 문장부호, · • ※만 남기고 나머지 인식 노이즈는 지웁니다.

고쳐주지 않는 것

틀리게 읽은 글자를 다른 글자로 바꿔 추측해주지는 않습니다. 예를 들어 원본의 "Card"를 "Cad"로 읽었다면 결과도 "Cad"로 남습니다 — "Card"로 자동 교정되지 않습니다. 오타 교정은 편집창에서 직접 해야 합니다.

TROUBLESHOOTING

막히는 지점을 빠르게 찾기.

"Windows에 한국어 문자 인식기가 없습니다"가 표시됩니다.

설정 → 시간 및 언어 → 언어 및 지역 → 한국어의 언어 옵션에서 광학 문자 인식을 설치한 뒤 앱을 다시 시작하세요.

텍스트 추출이 오래 걸리거나 끝나지 않습니다.

인식 시간 제한은 기본 60초입니다. 이미지가 매우 크면 명령줄에서 --timeout으로 제한을 늘려 다시 시도하세요.

표나 항목이 뒤죽박죽으로 섞여 나옵니다.

같은 줄 높이로 인식된 항목만 탭으로 묶입니다. 원본의 줄 배치가 심하게 어긋나 있으면 결과도 어긋날 수 있으니 편집창에서 정리하세요.

저장한 PDF에 편집창에서 고친 내용이 보이지 않습니다.

PDF의 텍스트는 인식 시점의 좌표에 얹히므로 이후 편집창에서 고친 내용은 반영되지 않습니다. 고친 내용을 남기려면 .txt 또는 .md로 따로 저장하세요.

"이미지가 너무 큽니다"가 표시됩니다.

Windows 인식기가 허용하는 최대 크기를 넘은 이미지입니다. 이미지를 줄이거나 필요한 영역만 잘라서 다시 시도하세요.
