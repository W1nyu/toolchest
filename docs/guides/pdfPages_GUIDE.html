LOCAL PDF MERGE & SPLIT

PDF를 합치고 나누되,
원본은 그대로.

여러 PDF를 원하는 순서와 원하는 쪽만 골라 하나로 합치고, 한 PDF에서 필요한 쪽만 뽑아 새 PDF로 만드는 로컬 도구입니다. 쪽마다 썸네일을 보여주므로 몇 쪽을 쓸지 눈으로 보고 클릭해 고를 수 있습니다. 파일은 외부로 전송되지 않고, 원본 PDF는 절대 수정되지 않습니다.

설치 및 실행 보기

THREE STEPS

따로 설치할 프로그램이 없습니다.

01

Python 설치

Python 3.10 이상을 설치합니다. 설치 화면에서 Add Python to PATH를 선택하세요.

02

패키지 설치

저장소 폴더에서 python -m pip install -r requirements.txt를 실행합니다. PDF 처리(pypdf)와 썸네일(pypdfium2)이 함께 설치됩니다.

03

앱 실행

프로젝트 루트 폴더의 로컬_변환기_실행.bat를 더블클릭한 뒤 PDF 합치기 또는 PDF 분할 탭을 엽니다.

Ghostscript나 Poppler 같은 외부 프로그램은 필요 없습니다. 원본 쪽을 그대로 복사하므로 화질·글자·링크가 손상되지 않습니다.

PDF 합치기

순서를 정하고, 파일마다 쓸 쪽을 고르고, 하나로.

기본 흐름

  1. PDF 추가로 합칠 파일을 고릅니다. 여러 개를 한 번에 고를 수 있습니다.
  2. 목록에서 행을 클릭해 ↑ 위로 / ↓ 아래로로 순서를 정합니다. 결과 PDF는 목록 순서를 따릅니다.
  3. 행을 고른 채 아래 썸네일을 클릭하거나 선택한 파일의 페이지 칸에 1-3, 5처럼 적습니다. 비워두면 그 파일 전체가 들어갑니다.
  4. 저장 폴더와 결과 이름을 확인하고 PDF 합치기를 누릅니다.

알아둘 점

  • 썸네일 클릭은 항상 오름차순으로 칸을 다시 씁니다. 같은 파일 안에서 쪽 순서를 바꾸고 싶으면(예: 3,1,2) 칸에 직접 적으세요. 그 뒤에 썸네일을 클릭하면 다시 오름차순으로 정리됩니다.
  • 같은 쪽을 두 번 넣을 수 있습니다(예: 1,1).
  • 결과 이름은 첫 파일 이름 뒤에 _합본이 붙습니다. 직접 고친 뒤에는 자동으로 바뀌지 않습니다.
  • 암호가 걸린 PDF는 목록에 추가되지 않습니다.

PDF 분할

필요한 쪽만 골라 새 PDF로.

기본 흐름

  1. 파일 선택으로 PDF를 고릅니다. 전체 쪽 수와 썸네일이 표시됩니다.
  2. 썸네일을 클릭하거나 분리할 페이지 칸에 2-4, 7처럼 적습니다.
  3. 결과 이름은 원본_p2-4,7.pdf처럼 자동으로 채워집니다. 필요하면 고치세요.
  4. PDF 분할을 누릅니다. 지정한 쪽만 담긴 새 PDF가 생기고 원본은 그대로입니다.

알아둘 점

  • 분할은 지정한 쪽을 한 파일로 모읍니다. 구간마다 파일을 따로 만들고 싶으면 여러 번 실행하세요.
  • 페이지 칸을 비운 채로는 실행되지 않습니다. 전체를 다시 쓰는 것은 분할이 아니기 때문입니다.
  • 범위는 작은 수에서 큰 수 순서로 적습니다. 5-3은 오류입니다.

같은 이름의 파일이 이미 있으면 덮어쓰지 않고 멈춥니다. 덮어쓰려면 같은 이름이면 덮어쓰기를 켜세요.

COMMAND LINE

반복 작업이나 스크립트에는 명령줄로.

두 파일 전체 합치기 (output\pdf\a_합본.pdf)

python src\pdf_pages.py merge a.pdf b.pdf

파일마다 쪽을 지정해 합치기

python src\pdf_pages.py merge a.pdf "b.pdf:1-3,5" c.pdf --output merged.pdf

2~4쪽과 7쪽만 분리하기 (output\pdf\in_p2-4,7.pdf)

python src\pdf_pages.py split in.pdf --pages "2-4,7"

저장 폴더 지정, 덮어쓰기

python src\pdf_pages.py split in.pdf --pages 1 --output-dir saved --overwrite

merge의 입력은 경로 또는 경로:페이지입니다. 경로가 .pdf로 끝나면 페이지 지정이 없는 것으로 봅니다.

PRIVACY & LIMITS

내 PC 안에서 끝나고,
원본은 건드리지 않습니다.

로컬 처리

pypdf와 pypdfium2만 사용합니다. 파일은 인터넷으로 전송되지 않습니다.

원본 보호

원본은 읽기만 하고, 결과는 임시 파일에 쓴 뒤 최종 이름으로 옮깁니다. 중간에 실패해도 반쯤 쓰인 파일이 남지 않습니다.

지원하지 않는 것

암호가 걸린 PDF, 쪽 회전·삭제, 북마크 편집, 드래그로 순서 바꾸기.

썸네일

pypdfium2가 없으면 썸네일 대신 안내 문구가 뜨지만 페이지 칸 입력으로 합치기·분할은 그대로 됩니다.

TROUBLESHOOTING

막히는 지점을 빠르게 찾기.

"썸네일을 그리려면 pypdfium2가 필요합니다"가 표시됩니다.

저장소 폴더에서 python -m pip install -r requirements.txt를 실행한 뒤 앱을 다시 시작하세요.

"PDF 파일을 읽을 수 없습니다"가 표시됩니다.

PDF가 아니거나 손상된 파일입니다. 다른 뷰어에서 열리는지 확인하세요.

"1부터 n 사이의 페이지만 지정할 수 있습니다"가 표시됩니다.

그 파일의 쪽 수를 넘는 번호를 적었습니다. 썸네일 아래 번호를 참고해 다시 적으세요.

썸네일 한 칸이 "?"로 나옵니다.

그 쪽만 미리보기를 그리지 못한 것입니다. 합치기·분할에는 영향이 없습니다.
