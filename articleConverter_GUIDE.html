LOCAL ARTICLE TO PDF

읽을 것만 남기고.
PDF로 간직합니다.

공개 웹페이지 주소 하나로, 광고·메뉴·댓글을 최대한 덜어낸 본문과 본문 이미지를 PDF로 저장합니다. 변환은 내려받은 PC에서 처리됩니다.

설치 및 실행 보기

THREE STEPS

한 번 설치하고, URL만 넣으세요.

01

Python 설치

Python 3.10 이상을 설치하고 설치 화면에서 Add Python to PATH를 선택합니다.

02

패키지 설치

이 폴더에서 requirements.txt의 PDF·HTML·이미지 처리 패키지를 한 번 설치합니다.

03

앱 열기

로컬_변환기_실행.bat를 더블클릭한 뒤 웹 본문 PDF 탭에서 공개 웹페이지 URL을 붙여넣습니다.

python -m pip install -r requirements.txt

자바스크립트로 본문이 만들어지는 페이지를 처리하려면 Microsoft Edge 또는 Google Chrome도 설치되어 있어야 합니다.

DESKTOP APP

브라우저 대신, 가벼운 로컬 앱에서.

별도 서버나 계정 없이 Windows 앱에서 주소를 넣고 저장 위치를 정합니다. 파일 변환기와 같은 앱을 쓰며, 웹 본문 PDF 탭이 이 기능입니다. PDF 파일명은 페이지 제목을 기준으로 자동 생성됩니다.

로컬_변환기_실행.bat 또는 python converter_gui.py

기본 흐름

  1. 앱 상단의 웹 본문 PDF 탭을 엽니다.
  2. 웹페이지 주소에 공개 URL을 붙여넣습니다.
  3. 필요하면 PDF 저장 폴더를 바꿉니다.
  4. 덮어쓰기·원본 URL 표시 옵션을 선택합니다.
  5. 본문 PDF 만들기를 눌러 완료 경로를 확인합니다.

결과 파일

  • 기본 위치는 tools 폴더의 output\pdf입니다.
  • 동일한 제목이 있으면 (2), (3)처럼 새 파일명을 만듭니다.
  • 덮어쓰기를 선택한 경우에만 같은 제목의 결과를 교체합니다.
  • 가져오지 못한 이미지는 PDF 생성 후 개수로 안내합니다.

WHAT IS KEPT

본문의 순서를 보존합니다.

포함제외하도록 시도처리 방식
본문 문단과 줄바꿈상단 메뉴, 푸터, 사이드바사이트별 본문 영역 또는 article/main 같은 일반 본문 영역을 우선 선택합니다.
본문 사이에 있는 이미지광고, 추천·관련 글, 댓글·답글텍스트와 이미지를 원문에 나타난 순서대로 PDF에 배치합니다.
가로·세로가 긴 이미지스크립트, 버튼, 입력 폼, iframe이미지는 페이지 폭에 맞추고, 너무 긴 이미지는 여러 PDF 페이지로 나눕니다.

웹페이지마다 구조가 다르므로 일반 URL은 결과를 먼저 확인하세요. 도구는 본문 후보를 선택하지만 원본의 모든 주변 요소를 완벽히 판별할 수는 없습니다.

PAGE TYPES

페이지 구조에 맞춰 본문을 고릅니다.

게시판·커뮤니티 글

게시글의 실제 내용 컨테이너를 우선 선택해 제목, 추천·공유, 댓글 영역을 분리합니다.

python web_to_pdf.py "https://example.com/community/post"

iframe 기반 블로그

공개 모바일 글 본문처럼 하나의 HTML 문서에 담긴 내용 영역을 우선 읽어 포스트 헤더를 덜어냅니다.

python web_to_pdf.py "https://example.com/blog/post"

정적 블로그와 문서

article, main, articleBody 같은 표준 구조를 찾아 본문과 이미지 순서를 PDF에 옮깁니다.

python web_to_pdf.py "https://example.com/2026/article.html"

자바스크립트 페이지

정적 HTML이 비어 있으면 로컬 Edge 또는 Chrome으로 렌더링한 DOM을 읽습니다. 로그인, CAPTCHA, 유료벽, 봇 차단은 우회하지 않습니다.

지원 여부는 페이지 HTML 구조와 해당 사이트의 접근 정책에 따라 달라집니다.

COMMAND LINE

반복 작업은 명령으로.

기본 저장

python web_to_pdf.py "https://example.com/article"

저장 폴더와 원본 URL 지정

python web_to_pdf.py "https://example.com/article" --output-dir "C:\PDF" --include-source

같은 제목 파일 덮어쓰기

python web_to_pdf.py "https://example.com/article" --overwrite

느린 페이지의 시간 제한 늘리기

python web_to_pdf.py "https://example.com/article" --timeout 60

URL은 http:// 또는 https://로 시작하는 공개 웹페이지여야 합니다. 기본 요청 시간 제한은 30초이고, 5초 미만으로 설정할 수 없습니다.

PRIVACY & LIMITS

내 PC에서 실행하고,
원문 권리는 존중합니다.

로컬 처리

이 도구는 URL에 직접 접속해 HTML과 본문 이미지를 가져오고, 설치된 Python으로 PDF를 생성합니다. 별도 변환 API나 원격 변환 서비스에 데이터를 전달하지 않습니다.

페이지 접근

로그인, 유료 구독, CAPTCHA, 봇 차단을 우회하지 않습니다. 변환에 실패하면 접근 제한일 수 있으며, 사이트의 이용 약관과 접근 정책을 따라야 합니다.

저작권

저장하려는 텍스트와 이미지를 PDF로 보관·공유할 권한이 있는지 사용자가 확인해야 합니다. 개인 보관에도 원문 사이트의 이용 조건이 적용될 수 있습니다.

이미지 실패

핫링크 제한, 지원하지 않는 이미지 형식, 25MB 초과 이미지는 건너뜁니다. 이 경우에도 읽어낸 본문 텍스트 PDF는 생성됩니다.

TROUBLESHOOTING

문제가 생겼을 때.

“필수 패키지가 없습니다”라고 나옵니다.

tools 폴더에서 python -m pip install -r requirements.txt를 실행한 뒤 다시 시작하세요. Python이 여러 개라면 앱을 실행한 같은 Python으로 설치해야 합니다.

동적 페이지에서 본문을 못 찾습니다.

Microsoft Edge 또는 Google Chrome을 설치하고 최신 상태인지 확인하세요. 도구는 둘 중 하나를 찾아 백그라운드 렌더링에 사용합니다.

PDF는 생성됐지만 일부 이미지가 없습니다.

원문 이미지 서버가 외부 요청을 막았거나 이미지가 너무 크거나 지원하지 않는 형식일 수 있습니다. 완료 알림의 건너뛴 이미지 개수를 확인하세요.

본문 대신 로그인·차단 화면이 저장됩니다.

그 페이지는 공개 본문을 제공하지 않는 상태입니다. 이 도구는 로그인이나 자동화 차단을 우회하지 않으므로, 공개 상태의 URL인지 확인하세요.
